# PPFP — 개인 투자 포트폴리오 관리

여러 포트폴리오를 계층으로 묶어 관리하고, 매수마다 생기는 Lot 단위로 매도하며, 기간별 수익률·손익·비중 변화를 추적하는 웹 앱(PWA)입니다. 상장 종목 시세와 계좌 보유종목은 연결한 증권사 Open API(토스·한국투자·키움·LS·DB·메리츠)에서, 코인 시세·보유·거래내역은 코인 거래소 Open API(업비트·빗썸·코인원·코빗)에서 받아옵니다.

명세서 1단계(MVP) 범위를 구현했습니다. 실주문은 포함하지 않습니다.

화면별 사용법은 **[사용설명서](docs/user-guide.md)**에 화면 캡처와 함께 정리돼 있습니다. 기능이 언제 추가되거나 사라졌는지(커밋 기준)도 거기에 있습니다.

## 기능

| 영역 | 내용 |
| --- | --- |
| 포트폴리오 계층 | 포트폴리오 안에 포트폴리오를 원하는 비율로 포함(DAG). 한 포트폴리오를 여러 상위에 나눠 넣을 수 있고, 할당 합계 100% 초과·순환 연결은 거부 |
| 자산 | 국내·미국 상장 종목(증권사 시세), 가상자산(원화마켓 코인, 거래소 시세), 부동산·예금·채권·펀드·대안자산·부채(수기 평가) |
| 매수 · 매도 | 매수마다 Lot 생성. 매도 시 직접 선택 / FIFO / LIFO / HIFO / LOFO / 이동평균 중 선택, 저장 전 Lot별 실현손익 미리보기 |
| 기업행위 | 분할·병합·무상증자 시 모든 Lot 수량·단가 일괄 조정 |
| 분석 | 전역 기간 선택(1D~전체, 사용자 지정), 총평가액·기간손익·TWR·최대낙폭·배당이자, 평가액/투자원금 추이, 자산배분(유형·통화), 비중 변화(100% 누적), 하위 포트폴리오 성과 |
| 증권사 연동 | 토스·한국투자·키움·LS·DB·메리츠증권 Open API. 사용자별·계좌별 키와 접근토큰을 AES-256-GCM으로 암호화 저장. 국내·미국 잔고, 현재가·환율·일봉(연결된 곳 중 응답하는 증권사에서) |
| 코인 거래소 연동 | 업비트·빗썸·코인원·코빗 Open API. 코인 시세·랭킹·호가·봉, 보유 현황, 체결·원화 입출금·코인 입출고 내역을 포트폴리오 원장에 그대로 재현(아래 참고) |
| 실시간 시세 | 주요 지수(코스피·코스닥·나스닥·S&P 500·다우)와 원/달러, 보유·관심종목 시세판(현재가·전일 대비·거래량·당일 미니차트·보유 평가와 오늘 손익), 국내·미국·코인 실시간 랭킹(거래대금·거래량·급상승·급하락), 종목 상세(캔들 차트와 거래량, 1분·5분·15분·1시간·4시간·일·주봉 선택 · 10단계 호가). 브라우저가 몇 초마다 갱신하고, 서버는 종목별로 짧게 캐시해 증권사 호출 한도를 지킴 |
| 보유종목 가져오기 | 연결한 계좌의 보유종목을 골라 종목별로 포트폴리오 지정 → 증권사 평균단가로 시작 Lot 생성. 계좌별로 이미 가져온 수량을 기억해 다시 가져오면 차이만 제안. API가 없는 증권사(하나·미래에셋·KB 등)는 잔고 표 붙여넣기·CSV·XLSX 업로드 |
| 가져오기 · 내보내기 | 포트폴리오·거래 내역·매매일지·메모·독서 노트·투자 거장·키워드를 한 형식(XLSX 시트별 또는 CSV)으로 내보내고 다시 가져오기. 미리 보기에서 추가·중복·오류를 행별로 확인, 같은 파일을 다시 넣어도 중복 없음. 본문은 마크다운. 형식 안내와 샘플 파일. 보유·Lot·실현손익·일별 스냅샷 보고서는 내보내기만 |
| 기타 | 금액 가리기, 상승/하락 색상 반전, 다크 모드, 감사 로그, 홈 화면 설치(PWA) |

## 시작하기

필요: Node.js 20.9+, PostgreSQL 14+

```bash
npm install
cp .env.example .env          # DATABASE_URL, APP_ENCRYPTION_KEY, CRON_SECRET 채우기
npx prisma migrate dev --name init
npm run dev                   # http://localhost:3000
```

`APP_ENCRYPTION_KEY` 생성:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

가입 후 **연동 · 설정**에서 증권사 개발자 포털에서 발급한 앱키/시크릿을 입력하면(한국투자증권은 계좌번호도) 연결을 확인한 뒤 저장합니다. 키는 `.env`가 아니라 사용자마다 앱에 입력합니다. 그다음 **보유종목 가져오기**에서 계좌 보유종목을 포트폴리오에 넣습니다.

### 봉(캔들) 차트

시세판 종목 상세에서 1분·5분·15분·1시간·4시간·일·주봉을 고를 수 있고, 아래에 거래량 막대가 함께 나옵니다. 마지막으로 고른 간격은 브라우저에 기억됩니다. 그 간격을 직접 주는 곳이 없으면 더 짧은 봉을 시계 경계(한국 종목은 KST, 미국 종목은 뉴욕 시각, 주봉은 월요일 시작)에 맞춰 묶어 만들고 차트에 "더 짧은 봉을 묶어 만듦"으로 표시합니다(5·15·60분 ← 1분, 4시간 ← 1시간/1분, 주 ← 일). 묶을 봉 중 하나라도 거래량이 없으면 그 봉의 거래량은 비워 둡니다.

| 기관 | 1분 | 5·15·60분 | 4시간 | 일 | 주 |
| --- | --- | --- | --- | --- | --- |
| 토스증권 | ✓ | 1분봉으로 만듦 | 1분봉으로 만듦 | ✓ | 일봉으로 만듦 |
| 한국투자증권 | ✓ | 국내: 1분봉으로 만듦 · 미국: ✓ | 묶어 만듦 | ✓ | ✓ |
| 키움증권 | ✓ | ✓ | 묶어 만듦 | ✓ | ✓ |
| LS증권 | ✓ | ✓ | 묶어 만듦 | ✓ | ✓ |
| DB증권 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 메리츠증권 | ✓ (국내는 당일) | ✓ (국내는 당일) | 묶어 만듦 | ✓ | 일봉으로 만듦 |
| 코인 거래소 4곳 | ✓ | ✓ | ✓ | ✓ | ✓ |

### 코인 거래소

**연동 · 설정**의 기관 목록 아래쪽 *코인 거래소*에서 Access Key와 Secret Key를 입력합니다. 시세만 보려면 조회 권한 키로 충분하고, 키 발급 때 이 서버의 공인 IP를 허용 IP로 등록해야 하는 거래소(업비트 등)가 있습니다. 코인은 `KRW-BTC`처럼 원화마켓 코드로 저장되어 주식 종목코드와 겹치지 않고, 시세판의 관심종목·랭킹 *코인* 탭에서도 같은 코드를 씁니다.

| 거래소 | 포털 | 인증 | 체결 내역 | 원화 입출금 · 코인 입출고 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 업비트 | upbit.com → Open API 관리 | JWT HS512 + query_hash | 종료 주문을 7일 단위로, 주문별 체결로 평균 체결가 계산 | ✓ | 자산·주문·입출금 **조회** 권한, 허용 IP 필요 |
| 빗썸 | bithumb.com → API 관리 | JWT HS256 + timestamp | `/v2/orders/history`(체결 금액 포함) | ✓ | |
| 코인원 | coinone.co.kr → Open API | HMAC-SHA512 payload | 체결 단위, 90일 구간씩 | ✓ | 코인으로 낸 수수료도 반영 |
| 코빗(디지털엑스) | docs.digitalx.miraeasset.com | HMAC-SHA256 서명 쿼리 | **최근 36시간만**, 현재 보유 중인 코인만 | 최근 100건 | 거래소 제공 범위의 제한 |

**보유종목 가져오기 → 코인 거래소 거래내역**에서 거래소별로 넣을 포트폴리오와 시작일(기본 1년 전)을 고르면 다음과 같이 원장에 기록합니다.

- 시작일 이전부터 갖고 있던 코인·원화: 지금 잔고에서 기간 내 거래를 거꾸로 빼서 시작 잔고를 구하고, 시작일 직전에 거래소 평균단가의 시작 Lot과 원화 입금으로 넣습니다.
- 체결된 매수·매도: 포트폴리오 현금에서 나가고 들어오는 BUY/SELL로 기록하고 수수료도 함께 넣습니다(코인으로 낸 수수료는 받은 수량에서 빠짐).
- 원화 입금·출금: 외부 입출금(DEPOSIT/WITHDRAW). 출금 수수료는 FEE로 기록합니다.
- 코인 입고·출고: 그날 종가로 평가해 외부에서 들어오거나 밖으로 나간 Lot으로 기록합니다. 수익률에서는 외부 입출금으로 취급됩니다.
- 모든 기록에 거래소 주문·입출금 ID를 붙여, 다시 동기화하면 새 내역만 추가됩니다. 이후 동기화는 마지막 동기화 2시간 전부터 다시 읽어 늦게 반영된 체결을 놓치지 않습니다.
- 한 거래소 연결은 한 포트폴리오에만 동기화합니다. 코인 거래소 보유분은 이중 집계를 막기 위해 *보유종목 가져오기* 목록에는 나오지 않습니다.
- 원화마켓(KRW-) 거래만 다룹니다. BTC·USDT 마켓 체결은 건너뜁니다.

하나증권(1Q Pro, Windows OCX)·NH·삼성·신한·대신(Windows COM)은 웹 서버에서 호출할 수 없고, 미래에셋증권은 공개된 개인용 REST API를 확인하지 못했으며, KB증권(오픈베타)은 문서가 로그인 후에만 공개돼 연동하지 않았습니다. 이 증권사들은 잔고 붙여넣기로 가져옵니다.

## 일별 작업

기간 분석은 하루 한 번 저장하는 스냅샷을 읽습니다. 장 마감 후 아래 중 하나를 실행하세요.

```bash
# 서버 cron (07:10 KST 미국 장 마감 후, 16:10 KST 국내 장 마감 후)
10 7,16 * * 1-5  cd /app && npm run job:daily

# 또는 HTTP 스케줄러
curl -X POST -H "Authorization: Bearer $CRON_SECRET" https://<host>/api/cron/daily
```

과거 거래를 입력한 직후에는 대시보드의 **과거 기록 계산** 버튼이 과거 종가를 받아 첫 거래일부터 스냅샷을 만듭니다.

## 알림

가격 알림(직접 만든 것과 매매일지 목표가·손절가)과 포트폴리오 목표 비중 이탈은 서버가 직접 확인합니다. `next start`로 띄우면 서버 프로세스 안의 타이머가 가격을 1분마다, 비중을 10분마다 확인하므로 따로 설정할 것이 없습니다.

| 환경 변수 | 기본값 | 뜻 |
| --- | --- | --- |
| `ALERT_POLL_SECONDS` | 60 | 가격 알림 확인 주기(초, 최소 15) |
| `DRIFT_POLL_SECONDS` | 600 | 목표 비중 확인 주기(초, 최소 60) |
| `ALERTS` | (켜짐) | `off`면 타이머를 끕니다. 서버가 여러 대이거나 서버리스처럼 백그라운드 타이머가 멈추는 곳에서는 끄고 아래 주소를 스케줄러로 부르세요. |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | (자동 생성) | Web Push 키. 비워 두면 처음 쓸 때 만들어 DB에 암호화해 둡니다. 서버를 옮겨도 DB를 그대로 쓰면 기기를 다시 등록할 필요가 없습니다. |
| `VAPID_SUBJECT` | `mailto:admin@localhost` | 푸시 서비스에 알리는 연락처 |

```bash
# 타이머 대신 외부 스케줄러로 (1분마다)
* * * * *  curl -s -X POST -H "Authorization: Bearer $CRON_SECRET" https://<host>/api/cron/alerts
```

## 독서 노트 책 검색

독서 노트에서 책 제목으로 저자·출판사·출간 연도를 찾아 채웁니다. 한국 책은 카카오 책 검색, 영문 책은 Open Library(키 필요 없음)로 찾습니다.

| 환경 변수 | 기본값 | 뜻 |
| --- | --- | --- |
| `KAKAO_REST_API_KEY` | (없음) | 서버 기본 카카오 REST API 키. 사용자가 연동 · 설정에 자기 키를 넣으면 그 키를 씁니다. 둘 다 없으면 영문 책만 찾습니다. |

## AI 어드바이저

포트폴리오 매니저, 리서치 애널리스트, 매매일지 코치, 독서 큐레이터, 투자 거장 관점 에이전트는 Claude(Anthropic), ChatGPT(OpenAI), Gemini(Google), Grok(xAI), DeepSeek 중 사용자가 연동 · 설정에서 고른 모델로 동작합니다. 에이전트마다 다른 회사·모델을 고를 수 있고, 대화는 시작할 때의 모델로 이어 갑니다. 앱의 서비스 함수를 도구로 써서 숫자를 읽고, 데이터를 바꾸는 일(메모·가격 알림·목표 비중·일지 복기·일지 초안·읽을 책 추가)은 사용자가 확인 카드에서 실행해야 반영됩니다. Claude는 Anthropic SDK로, 나머지는 각 회사의 OpenAI 호환 Chat Completions로 부릅니다. 웹 검색은 Claude 모델에서만 되며 설정에서 끌 수 있습니다.

| 환경 변수 | 기본값 | 뜻 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (없음) | 서버 기본 Claude 키. 사용자가 연동 · 설정에 자기 키를 넣으면 그 키를 씁니다(`APP_ENCRYPTION_KEY`로 암호화해 저장). |
| `OPENAI_API_KEY`, `GEMINI_API_KEY`, `XAI_API_KEY`, `DEEPSEEK_API_KEY` | (없음) | 다른 회사의 서버 기본 키. 사용자 키가 있으면 그 키를 씁니다. 어느 회사의 키도 없으면 AI 어드바이저는 꺼져 있습니다. |

에이전트마다 **스킬**(SKILL.md 형식의 지침)을 붙일 수 있습니다. 사용자가 직접 쓰거나, skills.sh에서 설치 수 순으로 고른 투자 스킬을 GitHub에서 읽어 와 적용합니다. 에이전트는 스킬의 이름과 설명을 보고 맞는 질문에서 `use_skill`로 지침을 읽습니다. 스킬은 글로만 쓰이며, 함께 있는 스크립트는 가져오지도 실행하지도 않습니다. 커뮤니티 목록과 스킬 내용은 서버에서 1시간 동안 캐시합니다.

사용 금액은 토큰 사용량으로 추정합니다. 가격을 아는 모델은 그 가격으로, 모르는 모델은 입력 100만 토큰당 $10, 출력 $50으로 넉넉히 셉니다.

아침 브리핑과 알림 자동 분석은 사용자가 연동 · 설정에서 켭니다. 서버 타이머가 5분마다 브리핑 시각이 된 사용자를 찾아 보내고(`ALERTS=off`면 `POST /api/cron/alerts`가 같은 일을 합니다), 가격·목표 비중 알림이 오면 그 자리에서 AI 분석을 붙입니다.

휴대폰·PC 푸시 알림은 HTTPS로 서비스할 때만 켤 수 있습니다(`localhost` 제외). 아이폰은 iOS 16.4 이상에서 홈 화면에 추가한 앱에서만 됩니다.

## 계산 규칙 요약

- 금액·수량은 부동소수점을 쓰지 않습니다(DB `Decimal`, 코드 `Dec`).
- Lot 단가에는 매수 수수료·세금이 포함됩니다. 매도 수수료·세금은 소진 수량 비율로 각 Lot에 나눕니다.
- 해외 자산 원화 실현손익 = 매도대금×매도환율 − 원가×취득환율 (환차 포함).
- 외부 입출금(입금·출금, 현금 없이 등록한 자산)은 수익률에서 빠지고, 배당·이자는 수익입니다.
- 상위 포트폴리오 금액 = 직접 보유 + Σ(하위 금액 × 할당 비율). 순자산 전체는 모든 포트폴리오를 한 번씩 더합니다.
- 일별 기준은 한국 시간(KST) 날짜입니다.

## 알려진 제한 (MVP)

- 실주문, 리밸런싱 제안, 벤치마크 비교, 거래 Import, 2단계 인증, 로그인 시도 제한은 아직 없습니다.
- 과거 환율은 매일 저장된 값과 거래에 입력한 환율로 계산합니다. 연동 전 기간은 거래 환율 또는 `FALLBACK_USDKRW`를 씁니다.
- 거래 수정은 삭제 후 다시 입력합니다(감사 로그에 원본 보존). 이미 일부 매도된 Lot의 매수 거래는 매도를 먼저 지워야 삭제됩니다.
- 증권사 어댑터는 각 사 공식 문서·예제의 필드명으로 만들고 가짜 응답으로 테스트했지만, 실계좌 키로는 검증하지 않았습니다. 처음 연결할 때 응답이 다르면 **연동 · 설정**의 오류 메시지를 확인하세요.
- 호출 한도는 문서에 있는 값(한투 실전 20회/초·모의 2회/초, LS TR별, 메리츠 API별 10회/초 등)에 맞춰 보수적으로 제한합니다. 토스는 공식 수치를 확인하지 못해 약 8회/초로 제한합니다.
- 시세판은 폴링(몇 초 간격)이며 증권사·거래소 웹소켓 실시간 체결은 쓰지 않습니다. 봉은 간격에 따라 10초(1분봉)~10분(주봉)간 서버에 캐시합니다.
- 코인 거래소 어댑터도 각 거래소 공식 문서 기준이며 실계정 키로는 검증하지 않았습니다. 코빗은 체결 내역을 36시간만 제공하므로 그 이전 거래는 시작 잔고(평균단가)로만 들어갑니다.
- 일별 스냅샷은 앱 전체가 평일 기준이라 코인의 주말 가격 변동은 다음 평일 스냅샷에 반영됩니다.
- 일부 값은 공식 예제에 설명이 없어 응답을 검사해 씁니다(예: 한투 등락률 순위의 정렬 코드는 결과 방향이 맞을 때만 사용). DB증권 해외 분봉과 키움 미국 분봉의 시각은 거래소 현지 시각으로 해석합니다.
- 해외는 미국(USD) 주식만 다룹니다. 증권사 평균단가로 만든 시작 Lot의 취득 환율은 가져오는 시점의 환율입니다.
- 여러 사용자의 증권사 자격증명을 서비스가 보관·호출하는 방식이 각 증권사 약관상 허용되는지 확인이 필요합니다.
